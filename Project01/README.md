# Fungi Generator



The Fungi Generator is a blender geo-nodes tool that can be used to attach fungi to any object. 



In the modifiers tab you simply select a target for the fungi to attach to in the target object slot, toggle to the edit tab in blender and use the pen or draw tools to draw custom fungi paths. 



The scale of the Fungi can be randomized with the randomize scale slider



The color and material of the mushrooms can be customized and placed in the material slot 



The density of the fungi can be scrolled through with thew Density of Funi slider, the starting value is pretty nice at .528'. Less than this might be nice for details but it will look sparce if you are not careful. 



You can toggle between high poly and low poly fungi with a simple switch! 



Finally if the fungi aren't quite aligned with the target object you can use the rotation scroll to tweak the z axis rotation of the fungi.
